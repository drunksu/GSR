## 6. 阅读提示

- **预期形态**：C2（官方重置下的顺序主效应）≈ 0 → app 快照恢复确实挡住了同 app 污染；C1/C3（重置被削弱）显著为负 → 污染与顺序叠加才致命。若 C2 也显著，说明快照本身不可靠，这是更强的结论。
- **DiD > 0（更负）** 表示顺序效应只在重置不彻底时才被放大——这正是论文要讲的故事。
- victim 名单 = 需要 cleaner 的任务清单，也是恢复模块的评测集来源。
- CTCI 越大 = 评测越不可信；PASR 是评测公平性的可信下界。
